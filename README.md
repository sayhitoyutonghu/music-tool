# Eternal Research Pattern Tool Clone

A standalone Canvas recreation of the Eternal Research pattern generator experience.

## Run

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173/`.

## Features

- Generative mirrored vine/flourish pattern renderer
- Canvas size presets and manual dimensions
- Central text-safe space controls
- Density, straight-line, flourish, blank-area, and line-thickness controls
- Black, white, faint, and outline color modes
- Animation loop
- Audio upload and demo audio response
- PNG export
